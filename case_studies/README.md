# Case-study data access

The case-study raw data are **third-party** and are **not redistributed here** — they remain under their
original providers' terms. This folder contains only **our extraction scripts** (`jhtdb_*.py`); use them with
the sources below to regenerate the point clouds used in Figure 3 and §2 of the paper.

## Sources

- **Turbulence (Figure 3a; Kolmogorov 2/3 & 4/5 laws, law of the wall, Reynolds-stress closure).**
  Johns Hopkins Turbulence Database (JHTDB), datasets `isotropic1024coarse` and `channel5200`.
  Access: https://turbulence.pha.jhu.edu (register for a token; queried via the `givernylocal` client).
  Run `jhtdb_isotropic.py` (structure functions), `jhtdb_channel5200_loglaw.py` (law of the wall),
  `jhtdb_channel_stress.py` (Reynolds stress).

- **Astronomy (Figure 3b; Stefan–Boltzmann, Kepler's third law, insolation, equilibrium temperature).**
  NASA Exoplanet Archive, TAP service, table `pscomppars` (host-star and planet parameters).
  Access: https://exoplanetarchive.ipac.caltech.edu (public; NASA/U.S. Government data).

- **White-dwarf mass–radius (§2.5, variable-slope form).**
  Bédard, Bergeron, Brassard & Fontaine, *ApJ* **901**, 93 (2020), via VizieR catalog J/ApJ/901/93.
  Access: https://vizier.cds.unistra.fr

- **Epidemiology (mass-action incidence).**
  Synthetic SIR outbreak trajectories generated by our simulation (parameters in the paper Methods /
  Supplementary App. C); regenerable without external data.

## Note

Derived point clouds are small summaries computed from the above; to respect each provider's terms we ship the
code, not the data. All sources are openly accessible for registered/public use.
